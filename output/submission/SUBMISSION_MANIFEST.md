- **Formatting assumptions / environment adaptations made during conversion** (all deviations from a fully "official" build, documented for transparency):
  1. `pandoc` was not pre-installed in this environment; installed via `conda install -c conda-forge pandoc` (version 3.11) to enable this conversion. `latexmk` and `xelatex`'s companion tools were not available either; `pdflatex` + `bibtex` used instead (both were pre-installed).
  2. `cleveref` and `mdframed` (named in this skill's own template preamble) are not installed in this TeX Live 2018 environment and were dropped — neither was actually used by any converted content (the manuscript's cross-references are plain prose text, not `\ref`/`\cref`; no `[PLACEHOLDER ...]` block needed a boxed environment, since all three placeholders are short inline bracketed text).
  3. Section heading numbers ("5. Results", "5.1 Classifier accuracy") were stripped from the Markdown-derived LaTeX headings before wrapping in `\section`/`\subsection`, so LaTeX's automatic numbering (not manual text) drives the numbers — necessary so the numbering stays exactly consistent with the manuscript's own extensive internal "Section N.M" prose references.
  4. A handful of Unicode characters produced by pandoc (², ×, →, − minus sign, ≤) were replaced with LaTeX-safe equivalents (`\textsuperscript{2}`, `$\times$`, `$\rightarrow$`, `$-$`, `$\leq$`) to avoid `inputenc` build failures on this TeX Live 2018 install.
  5. In-text citations were prose ("Author et al., YEAR") in the source Markdown, not pandoc-citeproc `[@key]` syntax — converted to `\citep`/`\citet`/`\citealp`/`\citeauthor` via targeted regex per citation key (12 keys, all verified against `references.bib`) rather than a generic citation parser, since the source was never written in citeproc syntax.
  6. `sections_revised/*.md` was created as a mirror of `sections/*.md` for this package's provenance trail — `paper-review-loop` round 1 edited `sections/*.md` in place rather than writing only to `sections_revised/*.md` (a deliberate, documented deviation from that skill's stated convention — see `output/manuscript/REVISION_LOG.md`).
