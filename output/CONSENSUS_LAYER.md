# The consensus paddock layer

Generated by `consensus_layer.py` from `consensus.gpkg`. One polygon per paddock that at least 5 of the 9 annual segmentations agreed on, filtered to paddock scale and carrying what it grew each year.

## What the filter removed

| | polygons | ha |
|---|---|---|
| raw consensus | 25,082 | 931,602 |
| below 5 ha (never classified in any year) | 2,178 | 7,138 |
| above 300 ha (under-segmentation blobs) | 133 | 101,110 |
| **kept** | **22,771** | **823,354** |

The blob band is 11 % of the raw layer's area from 0.5 % of its polygons — which is why an unfiltered consensus layer looks fine by polygon count and is dominated by blobs by area.

## Columns

| column | meaning |
|---|---|
| `paddock_id` | identity across the nine annual segmentations (union-find on IoU) |
| `from_year` | the year whose segmentation supplied this outline |
| `n_years`, `median_iou` | how many years found it, and how closely they agree |
| `crop_<year>` | class of THAT year's polygon for this paddock; empty = abstained |
| `conf_<year>` | the classifier's probability for that class |
| `n_class_years`, `n_classes`, `canola_years`, `modal_crop`, `crop_seq` | rotation |
